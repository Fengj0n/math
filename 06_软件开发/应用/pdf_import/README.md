# 本地PDF题目导入（独立试用）

双击上一级的 **启动本地PDF导入.cmd**。浏览器打开本地导入页，可选择PDF、页码和章节。当前电脑的独立环境和模型已准备好；日常识别无需联网、API账号或按页付费。

1. 首次先选一页，点击“开始本地识别”。支持文字PDF与扫描PDF，统一按原页图像识别。
2. 按题号整理成草稿，左侧显示原页，右侧显示识别文字及公式。
3. 逐题核对、编辑、调整原页区域；错拆时可手动拆分或与下一题合并。跨页片段保留各自页码。
4. 只将“已核对录入”的题目加入独立试用库，未核对项仍是草稿。可导出JSON；题库页沿用当前独立设计预览的筛选、知识点/考法和专题题单。
5. 页面中的“关闭导入”停止本地服务。识别中的页面结束后退出，下次启动可继续。

## 保存位置与边界

- 数据、PDF副本、原始识别、逐题草稿和批次记录：`06_软件开发/PDF导入试用/用户数据`。
- 模型及缓存：`06_软件开发/开发依赖/pdf-import-cache`。
- 独立Python环境：`06_软件开发/开发依赖/pdf-import-venv`。不替换正式软件运行环境。
- 正式软件、最终版数据库及源PDF均不写入。Git仅保存源码和说明，模型、上传文件和个人草稿不提交。
- 本地页面只监听127.0.0.1。识别进程禁止连接非本机地址；页面公式资源来自项目现有KaTeX，不加载外部资源。

## 已知能力与限制

真实识别使用Pix2Text 1.1.4、中文OCR与ONNX CPU模型。本机扫描页抽测约21秒，整批第一次启动还需加载环境；页数、清晰度及公式数量会影响耗时。此速度不代表全量性能保证。

**本地识别可以用，但不是免校对录入。** 已实测出现符号误读、相邻公式粘连、选项字母误认及水印噪声。确认录入只表示人已对照抄录，不认证数学正确性；导出仍标为“待人工检查”、不可自动用于正式组卷。

第一版优先连续单栏、题干与答案在同一内容段落中的资料。独立答案PDF、书后集中答案的自动匹配、多栏顺序、复杂表格/图形的结构化均未实现。图形仍由原页区域保留，不重新绘制。没有匹配到的答案留空，可人工补充，不推断补全。可先导入无答案题并保留草稿，但缺答案时不能确认入库。

拆分时原选项及答案留在前一题，后一题须手动分配；两题均保留原始识别及原页。合并保留原两份草稿与操作前快照。正文完全一致或相同来源稳定编号在试用库内跳过重复；暂未与正式全库或不同版本资料进行语义查重。已入库题目是当时核对结果的快照，后续草稿修改不会静默覆盖它；第一版未提供入库后的替换操作。

## 在另一台电脑准备

要求Python 3.12，预留约3GB磁盘（按实际环境为准）。在“应用”目录中依次执行：

```powershell
python -m venv ..\开发依赖\pdf-import-venv
..\开发依赖\pdf-import-venv\Scripts\python.exe -m pip install -r requirements-pdf-import.txt
..\开发依赖\pdf-import-venv\Scripts\python.exe -m pdf_import.setup_models
```

安装和首次准备模型需要下载公开软件与权重，不上传用户PDF。模型首次准备完后才可以离线识别。模型来源、指纹及大小记录在缓存目录`models.json`。后续更新模型须重新运行准备并重新实测，不代表自动提高数学准确率。

开发验证：`python -m pytest pdf_import/test_import.py -q`；测试另需pytest与httpx。真实扫描验证入口：`python -m pdf_import.smoke_ocr <PDF路径> --page 1 --output <记录路径>`。

实现依据：[Pix2Text官方项目](https://github.com/breezedeus/Pix2Text)、[官方安装说明](https://pix2text.readthedocs.io/zh-cn/latest/install/)、[模型说明](https://pix2text.readthedocs.io/zh-cn/latest/models/)。
