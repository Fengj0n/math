# 数研智枢：当前源码

正式交付版仍为 Math2Studio 1.2.0，入口是上一级目录的“启动数学二软件.cmd”。其程序、页面和用户数据本轮均未覆盖。

## 命题分析预览（2026-10-15）

当前源码已接入确认后的命题分析界面。运行上一级目录的“启动命题分析预览.cmd”，使用现有本地运行依赖和前端构建，不依赖聊天中的设计稿。

命题分析下设“试卷分析 / 难度评估”。试卷分析包含年度试卷与完整考法目录，保留章节分值图和原题联动；难度评估采用年度双堆叠柱。页面通过现有本地API读取2014—2026年真题，原题按需读取当前修订。未完成正文核验的题显示已有原页，不因此获得选题资格。

预览独立数据目录为 `06_软件开发/命题分析预览`，初始数据库通过SQLite一致性备份从正式版复制。预览中后续的笔记、试卷或其他修改只进入此副本，不自动写回正式版。再次启动预览不覆盖副本。

题库及其他模块保持当前软件实现，其他会话的设计稿不在本次接入范围内。

## 运行与构建

React、TypeScript、FastAPI、SQLite、KaTeX和开发依赖保留。前端在 `frontend` 构建，输出 `frontend/dist`；源码服务使用这里的页面。正式交付程序加载自己的 `_internal/frontend/dist`，本轮未修改该目录。

直接运行 `launcher.py` 仍可能默认使用正式数据，预览请使用专用入口；隔离测试必须设置 `MATH2_HOME`。正式数据库位于 `交付/Windows_v1.2.0_02/Math2Studio/用户数据/math2.sqlite3`。

`analysis.json` 是历史统计快照，保留供其他既有功能使用；新版命题分析不依赖此快照。`scripts/prepare_analysis.py` 不应覆盖当前数据库中的修订。
