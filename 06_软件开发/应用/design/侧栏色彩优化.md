# 侧栏色彩优化

日期：2026-10-15。

## 问题与方向

预览中的全局侧栏使用深藏蓝 `#17243a`、蓝灰选中态和亮紫蓝图标，与命题分析、题库设计稿共用的灰绿纸白背景及森林绿强调色差距过大。左栏容易成为整页最醒目的区域。

本轮将全局侧栏调整为浅雾灰绿。以接近右侧页面的明度建立连续背景，以灰色文字和细分隔线区分结构，只在当前模块、当前子页和键盘焦点上使用绿色。导航宽度、菜单结构及右侧模块样式保持现有设计。

## 官方设计参考

- [Linear：How we redesigned the Linear UI](https://linear.app/now/how-we-redesigned-the-linear-ui)：通过表面、文字、图标和控件的配色关系建立层级，降低导航噪声；文中也说明通过减少蓝色色度让界面更中性。本项目借鉴其颜色克制和统一层级的思路。
- [Vercel Geist：Colors](https://vercel.com/geist/colors)：默认使用灰色处理文字、图标、填充与边框，以有限的背景差异区分表面，分别定义默认、悬停和激活状态。本项目借鉴其相邻浅色表面和状态分层方法。
- [Atlassian：Color](https://atlassian.design/foundations/color)：中性色用于多数背景与文字，导航等次要界面使用 neutral 色彩角色。本项目将普通导航设为中性色，绿色用于当前所在位置。

以上为设计原则参考，最终色值根据本项目已有灰绿配色制定，并非照搬产品截图或声称所有产品使用同一种侧栏颜色。

## 本轮配色

| 用途 | 色值 | 处理 |
| --- | --- | --- |
| 侧栏背景 | `#f0f3ef` | 与命题分析右侧 `#f5f7f4` 自然过渡 |
| 分隔线 | `#dce3dc` | 细线区分导航与内容 |
| 普通文字 | `#536159` | 灰绿色，保留清晰度 |
| 普通图标 | `#6c7b71` | 比文字稍轻 |
| 悬停背景 | `#e7ece6` | 中性轻提示 |
| 当前模块背景 | `#e4ebe3` | 浅绿，配左侧细指示条 |
| 当前子页背景 | `#dce8de` | 比模块略深，便于识别实际所在页面 |
| 强调文字与焦点 | `#286347` | 复用模块设计的森林绿 |
| 标题文字 | `#293c30` | 深灰绿 |

标志保留原有数学符号与节点图形，改为森林绿底、纸白符号和低饱和节点。窄屏弹出子菜单使用同一浅色配色，阴影同步减轻。

## 验证与交付范围

- 前端类型检查和生产构建通过。
- 已检查1440px桌面宽度下的试卷分析、难度评估与当前题库页面，以及720px宽度下的导航弹出菜单。
- 已检查模块切换、子页切换、悬停与键盘焦点，未发现页面脚本错误。
- 普通文字、选中模块文字、选中子页文字及悬停文字与各自背景的对比度均超过4.5:1。
- 本轮更新源码及独立预览的前端构建；正式交付包未覆盖。
- 题库独立设计稿及右侧业务功能未在本轮改动，题库接入工作由对应会话处理。
