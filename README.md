# 数研智枢

考研数学二题库、命题分析与出卷软件。

当前源码位于 `06_软件开发/应用`。命题分析的新设计稿位于 `06_软件开发/应用/design/analysis-module.html`，目前用于讨论界面，尚未接入正式软件。

“素材库”在当前源码中统一更名为“题库”。题库设计调研见 `06_软件开发/应用/design/题库设计调研.md`；独立交互设计稿为 `06_软件开发/应用/design/question-bank.html`，当前试用顶部章节选择器和宽幅完整题面列表，不常显章节侧栏，保留78道现有题目的抽样预览，并增加PDF导入流程演示。导入示例支持原页对照、编辑核对、待检查草稿和重复题跳过，尚未连接真实PDF识别。设计稿用于讨论修改，尚未接入软件，交付程序尚未更新。

## 软件重设计约定

每个会话承担一个模块的独立设计，全部模块讨论完成后，再由用户汇总到最终软件。本次题库设计会话只负责题库模块。现有软件存在较大问题，整体导航、模块结构和界面均可重做，不以现有软件侧栏或视觉外壳作为设计约束。未经用户明确要求，不将模块设计接入软件。

仓库保存源码、软件内置资源和设计稿。原始PDF、交付程序、运行依赖、最终版数据库及用户内容在本地保留。
