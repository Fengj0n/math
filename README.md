# 数研智枢

考研数学二题库、命题分析与出卷软件。

当前源码位于 `06_软件开发/应用`。命题分析设计稿位于 `06_软件开发/应用/design/analysis-module.html`。确认后的界面已接入源码，通过 `06_软件开发/启动命题分析预览.cmd` 运行；正式交付版暂未覆盖。

“素材库”在当前源码中统一更名为“题库”。题库设计调研见 `06_软件开发/应用/design/题库设计调研.md`；独立交互设计稿为 `06_软件开发/应用/design/question-bank.html`，当前采用顶部章节选择器和宽幅完整题面列表，知识点与考法分别筛选，“收藏与题单”支持按专题保留题目及选用理由，不增加常驻侧栏。78道原有抽样题保留。该HTML内的PDF流程仍为演示；另已实现独立本地真实识别试用，双击`06_软件开发/应用/启动本地PDF导入.cmd`体验，说明见`06_软件开发/应用/pdf_import/README.md`。无需外部识别API，扫描页可识别后人工核对，结果保存到独立试用库。设计稿与本地识别模块均未接入正式软件。

## 软件重设计约定

每个会话承担一个模块的独立设计，全部模块讨论完成后，再由用户汇总到最终软件。本次题库设计会话只负责题库模块。现有软件存在较大问题，整体导航、模块结构和界面均可重做，不以现有软件侧栏或视觉外壳作为设计约束。未经用户明确要求，不将模块设计接入软件。

仓库保存源码、软件内置资源和设计稿。原始PDF、交付程序、运行依赖、最终版数据库及用户内容在本地保留。
