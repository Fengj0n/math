# 数研智枢

考研数学二题库、命题分析与出卷软件。

当前源码位于 `06_软件开发/应用`。命题分析的新设计稿位于 `06_软件开发/应用/design/analysis-module.html`，目前用于讨论界面，尚未接入正式软件。

仓库保存源码、软件内置资源和设计稿。原始PDF、交付程序、运行依赖、最终版数据库及用户内容在本地保留。

## 版本检查点

- `checkpoint-20261014-design-v1`：现有软件源码与命题分析第一版设计稿。
- `checkpoint-20261014-design-v2`：删除设计稿顶部的介绍标题。
- `checkpoint-20261014-two-part-analysis`：收为试卷分析与近13年难度评估两个入口，移除两题对照，增加可追溯到原题的分值构成图与逐题难度图。
- `checkpoint-20261014-analysis-drilldown`：增加单卷考点分值图，并支持定位较难题、高计算量题及对应原题。
- `checkpoint-20261015-paper-outline`：增加试卷骨架，按题型展示题位、考查任务与难度和计算量搭配，可展开原题。
- `checkpoint-20261015-clear-navigation`：视图入口直接显示，清理重复说明文案，放大保留的数据文字。
- `checkpoint-20261015-estimated-difficulty`：命题分析下设试卷分析、难度评估两个入口，移除逐题评级理由，保留难度和计算量的粗略预估。
- `checkpoint-20261015-full-topic-catalogue`：取消四个固定示例入口，按章节直接展示全部考法及对应真题。
- `checkpoint-20261015-merged-paper`：试卷骨架与年度试卷合并，统一查看题型结构、章节分值及原题；试卷分析内保留年度试卷和考法研究两个视角。
- `checkpoint-20261015-paper-split`：年度试卷改为左侧选题、右侧阅读，整卷统计按需展开；考法年份仅显示实际出现年份。
- `checkpoint-20261015-visible-chapter-chart`：年度试卷左侧常显考点分值图，点击章节后，右侧题号与原题同步更新。
- `checkpoint-20261015-compact-difficulty`：难度评估改为左侧年度双指标短柱对照、右侧年份明细和原题，保留较难题及高计算量筛选。
- `checkpoint-20261015-assessment-first`：难度评估以整页历年分值比较为主体，压缩行距并标注分值；逐题评级置于下方，原题按需展开。

后续每完成一项明确修改，保存一次提交；较大改动前增加检查点。可以针对具体文件恢复，也可以撤销某次提交。Git回退范围是源码与设计稿，数据库中的题目修订、笔记和试卷单独保留。

界面文案使用直接的功能名称和数据，避免口号与重复提示。试卷分析的视图入口直接可见，保留的辅助数据使用清楚的字号。
